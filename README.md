# Exercício Spring com DTO

Este projeto é um exercício básico para demonstrar o uso do Spring Boot com o padrão DTO (Data Transfer Object). O objetivo é organizar o código de forma clara, separando as camadas de entidade, serviço, controller e DTO, seguindo boas práticas tradicionais de desenvolvimento em Java.

---

## Tecnologias utilizadas

- Java 21 
- Spring Boot
- Maven
- H2 Database 


---

## Descrição do Projeto

Este sistema simples exemplifica um CRUD básico utilizando Spring Boot, onde os dados são transferidos entre camadas usando DTOs para desacoplar a entidade do banco dos dados da API exposta. O projeto inclui:

- Entidades JPA
- DTOs para transferência segura de dados
- Controller REST para endpoints HTTP
- Camada Service para lógica de negócio
- Repositório para acesso ao banco de dados
